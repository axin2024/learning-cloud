# 职业教育与企业培训平台｜状态与操作契约

## 学习资格的生命周期

预留→已报名→学习中→完成或退班。换班冻结原成绩快照，证书独立经过有效、到期、撤销。

## 权限与操作者

教务管班期和容量，讲师阅卷，学员查看本人进度，企业管理员分配本企业席位并查部门成果。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 批量分配输入企业合同、班级和部门名单，返回逐行占用、重复或额度不足。
2. 考试提交绑定场次、答卷和最后保存版，超时由服务器收卷；阅卷后按冻结规则计算总评。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 租户与课程 | 课程内容、通过要求和版权授权绑定发布版本，在学者保留原学习要求。 | 无授权素材阻止公开课程发布。 |
| 班期与招生 | 席位由班期统一预留，重复报名返回原资格，换班时检查目标容量及学时映射。 | 换班目标已满则原报名仍有效。 |
| 企业购课 | 企业采购限定有效期和课程，管理员只能分配本租户已购余量。 | 已激活学习资格不可作为未用名额回收。 |
| 学习过程 | 播放器和直播提供方上报区间，合并重叠片段并按课规判断完成；掉线允许续学。 | 缺少会话归属的出勤回执进入复核。 |
| 作业与辅导 | 按截止时间和宽限规则处理，重交保留原提交，助教只见所授班。 | 截止后无授权不能替换原提交。 |
| 题库与考试 | 开考冻结题目与评分要点，保存答题进度，补考使用独立场次并执行成绩采用策略。 | 网络重复交卷仅产生一次定稿成绩。 |
| 证书与复训 | 签发前核验学时、作业和考试，吊销保留原因。到期后生成复训任务并关联原资格。 | 复训提醒重复执行不重复分配任务。 |
| 经营与企业报告 | 按报名与完成时间点分别统计，先修条件限定进入资格，企业只看本单位学员。 | 退课后仍保存历史成绩并排除有效席位。 |

## 失联、中断及恢复

分配锁名额池，交卷按场次与尝试号定稿，发证检查成绩、学时及证书唯一键。按企业、班期、完成状态分页。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

补考覆盖规则只作用于总评，原卷与原评分均可回看；转班学时须有课程等价关系。 学习时长记 10 分钟；满足班规其他条件后按补考规则发一张有效证书，部门合计不超过 100 席。
