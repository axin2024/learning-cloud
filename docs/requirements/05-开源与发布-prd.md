# 职业教育与企业培训平台｜独立开源与发布

## 自托管发行

建议仓库名 **learning-cloud**，主工程采用 PHP，数据库采用 MySQL 8.4。基础交付含管理入口、业务处理进程、数据迁移、健康检查和独立公开样例。快速开始从空库建初始管理员、导入样例，直到得到第一份可核对结果。

**演示包组成**　授权短课、两个班、部门管理员与可回放出勤事件。

**自托管者需配置**　视频平台回传区间、角色与会话号；企业导入名单，证书查询只展示获准公开的最小属性。 第三方服务凭据与外部费用由部署者配置；本地演示可用固定夹具，界面标注回放。

## 贡献入口与兼容约束

课程包、试题导入、直播出勤适配器；演示课件须含再分发依据。

扩展声明支持的格式版本、权限、幂等策略、取消行为及部分失败的返回格式。贡献者提交最小复现输入与期望结果。维护者在清洁环境回放对应业务验收，并核对前一受支持版本的历史记录可继续读取。

## 软件许可和素材

候选软件许可为 Apache-2.0，公开前由项目所有者确认。发行应包含许可正文、第三方声明、依赖清单和素材权利表。样例仅使用原创或明确可再分发的内容。模型权重、字体、媒体与源码分别登记许可。安全问题在私密反馈通道处理，公开示例和日志须清除个人资料、私有业务数据及凭据。 [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)

## 版本与维护

需求定稿后进入开发；实测通过后再创建公开发行。首版需附中文 README、配置参考、升级和备份恢复说明、已知限制、贡献指南、问题模板及支持版本。GitHub 与 Gitee 双发时核对同一标签的提交和文件摘要。变更破坏公开接口时记录迁移窗口与旧格式读取策略。

**首个发行的判断依据**　独立使用者按教程验证「租户与课程」到「经营与企业报告」，并复现以下异常：网络重复交卷仅产生一次定稿成绩。
