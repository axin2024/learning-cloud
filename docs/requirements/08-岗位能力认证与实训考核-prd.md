# 职业教育与企业培训平台 2.0 产品需求文档

**岗位能力认证与实训考核**
需求评审版 · 2026-11-26 · 计划基线 v1.1.0（43a18ad）

## 产品目标与交付边界

当前发行覆盖课程、班期、考试和证书。本版支持以下业务流程。企业为岗位定义可观察的能力，学员提交实训作品，双评及申诉后签发可验证的能力凭证。 [现有项目说明](../../README.md) · [上一版业务需求](02-业务与交互-prd.md)

班期按发布量规计算。团队交付件与个人达标结论分别存储。公开证书仅供验证签发状态。

## 使用者与工作台

认证负责人发布标准，导师出题，学员交付，评委看匿名件，企业管理员看本企业汇总。

学员在量规旁标记证据页码或视频时间段。评委打开匿名作品逐维度给分并写理由，申诉员看到争议维度和两份锁定记录，外部查验只显示授权字段。

## 功能需求

下列六项均纳入正式版本。验收编号按项目独立，后文列出每项的触发条件和预期结果。

| 需求 | 模块 | 产品行为与约束 | 验收 |
| --- | --- | --- | --- |
| R1 | 岗位标准 | 负责人编制能力树、等级与证据要求，发布后按班期冻结评分标准。 | A1、A2 |
| R2 | 实训任务 | 导师发布任务书、样例和截止时刻，分配个人或小组角色，发放独立材料。 | A3、A4 |
| R3 | 作品证据 | 学员上传版本、标记作品中的证据位置，提交后保存摘要与时间。 | A5、A6 |
| R4 | 盲评校准 | 隐去作者信息，两位评委独立打分，分差超阈值由第三人裁决。 | A7、A8 |
| R5 | 认证申诉 | 认证员检查必达维度，签发可撤销凭证，学员可针对某项评分申诉。 | A9、A10 |
| R6 | 企业能力盘点 | 负责人按岗位看证据覆盖与缺口，生成复训名单，复训后跟踪能力提升。 | A11、A12 |

## 页面操作与回执

| 关联需求 | 角色与入口 | 操作细节 | 需要读回的字段 |
| --- | --- | --- | --- |
| R1 · 岗位标准 | 认证主管/量规编辑 | 预览各维度权重与硬门槛，锁定关联班期 | rubric_rev、required_dimensions |
| R2 · 实训任务 | 导师/任务分派 | 按班组发放材料，核对组员和个人贡献要求 | brief_rev、assignment_ids |
| R3 · 作品证据 | 学员/作品提交 | 在图片、文档或视频标注证据位置并冻结尝试 | attempt_id、evidence_manifest |
| R4 · 盲评校准 | 评委/匿名评审 | 分别保存盲评，再将分差超过阈值的维度交第三人 | review_ids、arbitration_id |
| R5 · 认证申诉 | 学员与认证员/申诉单 | 限定申诉维度，记录复核理由与新旧凭证关系 | appeal_id、replaced_credential |
| R6 · 企业能力盘点 | 企业培训主管/能力缺口 | 按岗位汇总缺失证据，发起复训并回读达标人数 | cohort_id、qualified_count |

盲评材料去除姓名、学号和文件元数据。按维度取两位评委均值，触发仲裁的维度使用裁决分。最终分保留一位小数。

## 状态、权限与数据

作品 草稿→已交→双评中→待裁决或已定分→签发。申诉记录引用原评分，可产生替代凭证。

各维度 0–100 分，权重总和 100%。必达维度低于门槛即待补训，评分锁定时写入评委和量规版本。

MySQL 保存业务记录与操作回执。下列为新增逻辑对象和关键字段，所有归属组织的数据都须持有可校验的组织标识。

- `competency(level,rubric_rev)`
- `practicum(cohort,brief_rev)`
- `submission(attempt,artifact_hash)`
- `review(score,reviewer)`
- `credential(subject,revision,status)`

作品版本键由实训、提交主体和尝试号组成，凭证用不可预测查验号且可独立撤销。 写入前校验操作者对目标对象的权限与当前修订。详情、搜索、导出和后台重试按同一归属校验。保留决定者、请求号、前后状态、发生时间及关联证据编号。

## 核心接口与集成

主要写入入口为 `POST /practicums/{id}/submissions`。请求必填字段为 `team_id, attempt, artifact_hashes, rubric_rev`。成功回执提供 submission_id, missing_evidence, submitted_at。请求另带租户身份和幂等键。相同键及相同内容返回原业务编号，相同键对应不同内容返回 409。输入不满足业务约束时返回 422 和字段路径，身份无权限读取的跨租户对象返回 404。

需要异步处理时，接收事务同时写入业务记录与待处理事件，再返回 202 及回执查询地址。回读须显示当前状态、已完成步骤、上次失败原因和可重试条件。外部系统已受理但应答丢失时，按原请求身份核查实际结果。

### 合成请求与业务回执样例

请求体示例使用演练环境中的对象。带摘要的样例在开发验收时应替换为实际文件或参数的计算值。

```json
{
  "team_id": "G2",
  "attempt": 2,
  "artifact_hashes": [
    "sha256:aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa"
  ],
  "rubric_rev": 4
}
```

业务回执示例可由提交响应或后续状态查询取得。

```json
{
  "submission_id": "S2",
  "missing_evidence": [],
  "submitted_at": "2027-03-09T08:00:00Z"
}
```

缺个人贡献记录时返回 422，指出缺失成员和证据维度，草稿可继续补录。

## 升级、部署与恢复

已有课程完成记录作为先修证据导入，只有新版实训和评分满足要求后才签发岗位凭证。 在隔离副本运行迁移预检，输出记录数量、归属冲突和待处理编号。新增结构先部署，回填分批提交并保存游标，完成对账后按租户启用新入口。

演练时在首次成功写入新业务后中断进程，从检查点重启。核对作品清单摘要、评分版本及凭证撤销序列。需要退出试点时停收新请求，排空已受理操作并导出未决清单。涉及数据恢复时同时恢复数据库与关联证据，再核对外部已生效的动作。

### A13 认证口径

覆盖率分母为该部门应认证的在职学员，分子为持有当前有效且满足岗位要求凭证的去重人数。申诉中和尚缺证据的学员不计入分子。

## 分期交付

1. **标准与实训。** 交付可导入的样例和可读回的第一批业务对象，验证基础身份、归属及版本。
2. **双评及申诉。** 串通参与角色和执行入口，演练并发、重复请求及部分成功后的恢复。
3. **凭证与能力盘点。** 完成全流程验收、容量实测和旧版升级。随开源发行提供中文配置、样例输入输出、备份恢复步骤及已知限制。
